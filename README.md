# Combining the Angular Profile Projects

This repository contains the worked sample app for the [Combining the Angular Profile Projects](https://grails.apache.org/guides/angular2-combined/4/guide/index.html) guide on the Apache Grails site.

## Run the example

`./gradlew bootRun`

## Maintained at apache/grails-static-website

The guide narrative is maintained at https://github.com/apache/grails-static-website. Changes to the guide content go there; this repo holds the worked sample app only.
